# NSE Edge PWA — free starter

## Included
- Mobile-first installable PWA interface
- Paper trade ticket with basic planned-risk calculation
- Local paper journal and CSV export
- Risk settings stored on this device
- Offline app shell

## Not included
- No Angel One connection, live market data, live signals, or real order execution.
- No API secrets are requested or stored.
- Scanner intentionally shows no live feed until a trusted backend is connected.

## Free hosting with GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository and upload the files to its root.
3. Open repository Settings → Pages.
4. Select deploy from branch `main`, folder `/ (root)`, then Save.
5. After the HTTPS site is published, open its URL in Android Chrome.
6. Tap ⋮ → Install app / Add to Home screen.

A service worker requires HTTPS or localhost. Never commit broker credentials to GitHub.
